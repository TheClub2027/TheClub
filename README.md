# The Club

The Club is a browser-based football management game built with Next.js, React, TypeScript, Three.js and Supabase. Development is incremental; see [DEVELOPMENT_STATUS.md](./DEVELOPMENT_STATUS.md) for what is implemented, what has been tested, and what remains.

## Run locally

```bash
pnpm install
pnpm dev
```

## Current playable scope

- Start or continue a career, select a manager and club, manage a squad, tactics, contracts, transfers and club finances, and progress through seasons.
- Play through England's seven-level fictional pyramid. The 199 other country entries have a localized top flight and second division, with 10–30 top-flight teams and two-up/two-down movement. Club names use real city and town seeds with country-specific forms and local identities, and an international career includes both domestic tiers alongside England.
- Browse 200,000 deterministic, procedurally generated player records (115,000 first-team, 70,000 academy and 15,000 free agents) and 75,000 staff records. Every active career club receives an 18-player squad, 48 academy prospects aged 5–20 and club staff. The large searchable records are generated by application code, not stored as individual rows in Postgres.
- Use the academy pathway, basic player training, scouting, sponsorships, kit sales, board pressure and the Three.js Stadium Architect.
- Read the manager's live briefing for actionable injury, pressure, match-preparation, contract, cash-flow and youth-development signals, with links into the related management screens.
- Save multiple careers in this browser, choose which one to continue, export portable backups, or import a backup as a separate save. Existing single-career browser saves migrate into the new library.
- Use account-backed Supabase saves when the required credentials and database migration are configured; cloud loading still restores the most recently updated account save.

These features are a playable prototype, not a claim that every system in the master specification is complete. Country-specific cup and registration rules, deeper national tiers outside England, independent inactive-league simulation, international competitions, deep training schedules and long-save validation remain future work.

## Supabase cloud saves

Without Supabase credentials, careers stay in this browser. For account-backed saves, set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in `.env.local` and apply `supabase/migrations/20261121172753_create_career_saves.sql` to the project. The migration enables row-level security for career ownership. Never put a Supabase secret key in browser code.
